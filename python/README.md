# Python CLI Chatbot

A simple command-line chatbot written in Python.  
This project is part of my "One Project in Every Programming Language" challenge.

## Features
- Keyword-based replies
- Random fallback responses
- Conversation logging to `chat_log.txt`
- Graceful exit on `exit`, `quit`, or `bye`

## Run the chatbot

```bash
python chatbot.py
