# Node.js Sci-Fi CLI Chatbot

A futuristic command-line chatbot written in Node.js.  
Part 2 of my "One Project in Every Programming Language" challenge.

## Features
- Sci-fi themed personality (ASTRABOT-7)
- Keyword-based responses with cosmic flavor
- Random fallback replies for unknown inputs
- Persistent conversation logging in `chat_log.txt`
- Graceful exit commands (`exit`, `quit`, `bye`)

## Run the chatbot

```bash
node index.js
